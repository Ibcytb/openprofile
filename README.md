# 📖 만화 뷰어 (Manga Viewer)

픽시브 스타일 가로 넘김 만화 뷰어입니다. GitHub Pages로 바로 배포 가능한 단일 페이지 앱입니다.

---

## 📁 파일 구조

```
manga-viewer/
├── index.html       ← 메인 HTML
├── style.css        ← 스타일
├── script.js        ← 뷰어 로직 + 이미지 목록
├── images/          ← 이미지 파일을 여기에 넣으세요
│   ├── page01.jpg
│   ├── page02.jpg
│   └── ...
└── README.md
```

---

## 🖼️ 이미지 추가 방법

1. `images/` 폴더에 이미지 파일을 넣습니다. (jpg, png, webp 모두 가능)
2. `script.js` 상단의 `IMAGES` 배열을 수정합니다:

```js
const IMAGES = [
  { src: "images/page01.jpg", title: "1화 — 시작" },
  { src: "images/page02.jpg", title: "1화 — 2페이지" },
  // ... 계속 추가
];
```

---

## 🚀 GitHub Pages 배포

1. 이 폴더를 GitHub 레포지토리로 업로드
2. Settings → Pages → Source: `main` 브랜치, `/ (root)` 선택 → Save
3. 몇 분 후 `https://<username>.github.io/<repo-name>/` 으로 접속

---

## 🎮 조작 방법

| 동작 | 방법 |
|------|------|
| 다음 페이지 | → 키, 마우스 드래그, 화살표 버튼 |
| 이전 페이지 | ← 키, 마우스 드래그, 화살표 버튼 |
| 확대 | Ctrl+휠, +키, 핀치아웃(모바일) |
| 축소 | Ctrl+휠, -키, 핀치인(모바일) |
| 원래 크기 | 0키, ⊡ 버튼 |
| 처음/끝 이동 | Home / End 키 |
| 페이지 이동 | 하단 썸네일 클릭 |

---

## ✨ 주요 기능

- **픽시브 스타일 가로 뷰어**: 이미지가 나란히 붙어있고 양쪽 바가 옆 이미지를 가려줌
- **페이지 스냅**: 드래그 후 가장 가까운 페이지로 자동 정렬
- **플릭 제스처**: 빠르게 밀면 다음/이전 페이지로 이동
- **확대/축소**: 버튼, 키보드, 마우스 휠(Ctrl), 핀치(모바일)
- **썸네일 바**: 하단에서 페이지 미리보기 및 바로 이동
- **프로그레스 바**: 현재 위치 한눈에 확인
- **반응형**: 데스크톱 & 모바일 모두 지원
